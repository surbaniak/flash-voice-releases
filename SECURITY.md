# Security reports

Please report suspected vulnerabilities privately to **kontakt@appfly.pl**. Include the Flash version/build, macOS version, steps to reproduce, and the potential impact.

Do not include real API keys, private recordings, transcripts or other confidential content in public issues. Use synthetic examples where possible. The diagnostic report available in Flash's Privacy settings is intended to exclude content and credentials.

This repository contains binary releases only; application source code and development symbols are not published here.
